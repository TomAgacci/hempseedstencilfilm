Base film: hemp‑reinforced bioplastic (cellulose acetate matrix).

------------------------------------------------------------

Step 1 — Clean
Wash hemp hurds/hulls with clean water to remove dust and debris.

Step 2 — Dry
Dry at 80–90°C until moisture content is low and stable.

Step 3 — Mill
Grind to ≤50 µm powder for smooth film texture.

Step 4 — Optional Surface Treatment
A mild alkali wash (e.g., NaOH) can improve bonding, followed by
neutralization and thorough rinsing. Dry again.

------------------------------------------------------------
SECTION 4 — FILM FORMULATION
------------------------------------------------------------

Recommended Composition (by weight):
- 55–65% cellulose acetate
- 15–25% hemp filler powder
- 10–15% triacetin plasticizer
- 2–5% minor additives

Step 1 — Premix
Blend CA pellets, hemp powder, plasticizer, and additives.

Step 2 — Melt Processing
Extrude at 180–200°C (depending on CA grade) until homogeneous.

Step 3 — Sheet Formation
Extrude through a flat die onto a chilled roll or casting belt.

Step 4 — Calendering
Roll to final thickness of 0.05–0.12 mm (ideal for CNC stencils).

------------------------------------------------------------
SECTION 5 — MICRO‑TEXTURE ADHESION LAYER
------------------------------------------------------------

Step 1 — Embossing
Emboss one side of the film with a micro‑pattern:
- Dome/pillar features: 20–80 µm diameter
- Height: 10–30 µm

This creates controlled contact area for dry adhesion.

Step 2 — Hemp Alkane Coating
Fractionate hemp seed oil by cooling and filtering to isolate waxy
components. Mix with ethanol or similar carrier.

Apply an ultra‑thin coating (sub‑micron) using:
- Slot‑die coating
- Spray coating
- Dip‑coating with controlled withdrawal speed

Allow solvent to evaporate fully.

Result:
- Dry, low‑tack adhesion
- Repositionable
- Residue‑free

#!/usr/bin/env python3
"""
hemp_stencil_laser_helper.py

Helper tool for estimating laser-cutting parameters for hemp-based
stencil films. Provides starting values for CO2 or diode lasers.
"""

def suggest_settings(laser_type: str, power_watts: float, thickness_mm: float):
    """
    Suggest starting settings for cutting hemp-based stencil film.

    Parameters
    ----------
    laser_type : str
        "CO2" or "diode"
    power_watts : float
        Nominal laser wattage
    thickness_mm : float
        Film thickness in millimeters (e.g., 0.08)
    """
    laser_type = laser_type.upper().strip()

    if thickness_mm <= 0:
        raise ValueError("Thickness must be positive.")

    # Thickness scaling heuristic
    thickness_factor = max(0.5, min(2.0, thickness_mm / 0.08))

    if laser_type == "CO2":
        base_power_pct = 20.0
        base_speed = 280.0
        power_pct = base_power_pct * thickness_factor
        speed = base_speed / thickness_factor
        passes = 1 if thickness_mm <= 0.1 else 2

    elif laser_type == "DIODE":
        base_power_pct = 70.0
        base_speed = 150.0
        power_pct = base_power_pct * thickness_factor
        speed = base_speed / thickness_factor
        passes = 1 if thickness_mm <= 0.08 else 2

    else:
        raise ValueError("Unsupported laser type. Use 'CO2' or 'diode'.")

    # Clamp values
    power_pct = max(5.0, min(100.0, power_pct))
    speed = max(50.0, min(500.0, speed))

    return {
        "laser_type": laser_type,
        "power_watts": power_watts,
        "thickness_mm": thickness_mm,
        "power_percent": round(power_pct, 1),
        "speed_mm_s": round(speed, 1),
        "passes": passes,
    }


def print_test_plan(settings: dict):
    """
    Print a simple test plan based on suggested settings.
    """
    print("=== Hemp Stencil Film Laser Test Plan ===")
    print(f"Laser type      : {settings['laser_type']}")
    print(f"Laser power     : {settings['power_watts']} W")
    print(f"Film thickness  : {settings['thickness_mm']} mm\n")

    print("Suggested starting settings:")
    print(f"  Power         : {settings['power_percent']} %")
    print(f"  Speed         : {settings['speed_mm_s']} mm/s")
    print(f"  Passes        : {settings['passes']}\n")

    print("Test procedure:")
    print("  1. Place a small piece of film on the bed.")
    print("  2. Focus the laser at the film surface.")
    print("  3. Cut a 5x5 mm square using the suggested settings.")
    print("  4. Inspect edges for melt or incomplete cut.")
    print("  5. Adjust power/speed slightly and repeat.")
    print("  6. Apply final settings to full stencil designs.")
    print("===========================================")


if __name__ == "__main__":
    # Example usage
    settings = suggest_settings("CO2", 50.0, 0.08)
    print_test_plan(settings)
